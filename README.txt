MASTER Nutrisyon PWA v5.3 — Deployment

GitHub Pages:
1. Bu ZIP dosyasını açın.
2. İçindeki TÜM dosyaları GitHub repository kök dizinine yükleyin.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /(root).
7. Save.
8. Oluşan https://...github.io/... adresini açın.

iPhone/iPad:
Safari > Paylaş > Ana Ekrana Ekle.

Dosyalar:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

Not:
Yeni sürüm yayınlandıktan sonra eski service worker önbelleği kısa süre eski sürümü gösterebilir.
Gerekirse sayfayı yenileyin veya PWA'yı ana ekrandan kaldırıp yeniden ekleyin.
